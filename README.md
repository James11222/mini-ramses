## mini-ramses ##

The mini-ramses repository is a fork of the [main RAMSES repository][1]. It was created as a stripped-down version of the main code base created in order to facilitate the development of major updates of RAMSES' core routines. This stripped-down version is still available in the main branch.

A rapidly-evolving development of mini-ramses based on a completely changed data-structure is contained in the develop branch. This branch is probably buggy, use it only if you know what you're doing ;)


You can download the code by cloning the git repository using 
```
$ git clone https://bitbucket.org/ableuler/mini-ramses.git
```

For more information, check out the [mini-ramses wiki][2].
